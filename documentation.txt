=== WPProAtoZ ACF Membership Uploader - Documentation ===

Version: 2.0.1
Last Updated: May 2026

== Overview ==

The WPProAtoZ ACF Membership Uploader is a specialized frontend upload plugin built for paid membership websites. It enables logged-in members to create and manage **one single Pet Tracker entry** using Advanced Custom Fields Pro (ACF Pro).

Designed specifically for **Petracker.com**, the plugin supports rapid community mobilization when a pet goes missing by allowing members to upload photos and a video of their pet, which can then be shared with designated neighbors.

This plugin replaces the older "ACF Image & Video Frontend Submission" functionality with a more powerful, membership-focused system featuring one-entry-per-user logic and dynamic tier limits based on Paid Memberships Pro (PMPro).

== Mission Alignment ==

Petracker.com turns the panic of a missing pet into immediate, pre-planned action. 

By providing a simple, instant plan-of-action, we create hope and community involvement. The first critical step is notifying neighbors. A well-made video of the missing pet, previously introduced to the community, triggers sympathy and the human helper instinct.

This plugin powers the frontend upload experience so members can quickly build their Pet Tracker and get the word out.

== Key Features ==

- One Entry Per User: Automatically loads or creates the member's single Pet Tracker post
- Dynamic Tier Limits: Adjusts maximum images and video size based on the user's current PMPro membership level
- ACF Pro Integration: Works with your existing Gallery field (images) and File field (video)
- PMPro Account Page Integration: Automatically adds a "My PE Tracker" section to the membership account area
- Spam Protection: reCAPTCHA v3 (invisible) + honeypot fallback
- Admin Moderation: New submissions start as Drafts (configurable)
- Shortcode Ready: Easy placement on any protected page
- Clean, Responsive Frontend Form

== Requirements ==

- WordPress 6.0+
- Advanced Custom Fields Pro (ACF Pro)
- Paid Memberships Pro (PMPro) - required for tiered limits
- reCAPTCHA v3 keys (optional but recommended)

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/wpproatoz-acf-membership-uploader/`
2. Activate the plugin through the WordPress Plugins admin screen
3. Install and activate Advanced Custom Fields Pro and Paid Memberships Pro if not already active
4. Go to **Membership Uploader → Settings** in the WordPress admin menu

== Plugin Configuration ==

After activation, configure the plugin at **Membership Uploader → Settings**:

**Core Settings:**
- Custom Post Type Slug (default: `pe_tracker`)
- ACF Gallery Field Key (for images)
- ACF Video File Field Key (for video)
- Default Post Status (Draft or Publish)

**Membership Tier Limits:**
- Configure maximum number of images and maximum video size (in MB) for each PMPro membership level

**reCAPTCHA:**
- Enable reCAPTCHA v3
- Enter Site Key and Secret Key
- Set minimum score threshold (recommended: 0.5)

**Form Labels & Text:**
- Customize all frontend form labels, button text, success messages, and help text

== Usage ==

Add the following shortcode to a page that is restricted to logged-in members (using PMPro):

`[pe_tracker_uploader]`

This will display the complete frontend form with:
- Pet information fields
- Image gallery uploader
- Video uploader
- Submit / Update button

The plugin automatically:
- Finds the user's existing Pet Tracker (if any)
- Enforces tier limits
- Handles file validation and upload
- Saves to the configured Custom Post Type

== PMPro Integration ==

The plugin automatically adds a new section titled **"My PE Tracker"** to the Paid Memberships Pro Account page. Members can access their tracker directly from their account dashboard.

== Shortcodes ==

- `[pe_tracker_uploader]` — Main frontend form (recommended)

== Troubleshooting ==

Common issues and solutions:

1. **Form not showing** → Ensure the page is behind a PMPro membership level and the user is logged in.
2. **Upload fields missing** → Double-check that the correct ACF field keys are entered in plugin settings.
3. **Tier limits not applying** → Confirm the user has an active PMPro membership level.
4. **reCAPTCHA not working** → Verify Site and Secret keys are correct.
