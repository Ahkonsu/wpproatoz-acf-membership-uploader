WPProAtoZ ACF Membership Uploader - Documentation
Overview
The WPProAtoZ ACF Membership Uploader plugin provides a powerful frontend submission form for Paid Memberships Pro (PMPro) membership sites. It is built around Advanced Custom Fields Pro (ACF Pro) and enables logged-in members to manage a single "Pet Tracker" entry (one entry per user). 

Key capabilities include:
- Dynamic tier-based limits (e.g., number of images and video file size based on the user's PMPro membership level)
- Gallery (images) + File (video) field support
- Automatic integration into the PMPro "Account" page ("My PE Tracker" section)
- Public sharing with clean permalinks (/pet-tracker-page/ slug), even for drafts
- "Make Public" toggle that auto-publishes the entry
- Shareable link box with one-click copy functionality
- Spam protection (reCAPTCHA v3 + honeypot)
- Admin moderation (entries start as Drafts by default)
- Optional image/video uploads with delete functionality

The plugin is ideal for PetTracker.com and similar neighborhood-powered pet safety platforms.

Shortcodes
[pe_tracker_uploader]
Displays the frontend uploader form for the current logged-in user.
- Automatically creates a new tracker entry on first use or loads the existing one.
- Supports image gallery and video upload fields (configured via ACF).
- Includes dynamic limits based on PMPro tier.
- Shows current media with delete options and a video player.
- Features "Make Public" toggle and prominent "Share Your Tracker" section with live permalink.

Usage: Add [pe_tracker_uploader] to a dedicated page (e.g., "My Pet Tracker") and link it from the PMPro account area.

Setup Instructions
Installation:
1. Place the wpproatoz-acf-membership-uploader folder in /wp-content/plugins/.
2. Activate the plugin via the WordPress admin Plugins page.
3. Install and activate Advanced Custom Fields Pro (ACF Pro) and Paid Memberships Pro.

Configuration:
Go to Membership Uploader → Settings in the WordPress admin.

Required Settings:
- Custom Post Type Slug: Set the CPT slug (e.g., pe-tracker or pet-tracker).
- Gallery Field Key: ACF field key for the image gallery (e.g., field_abc123...).
- Video Field Key: ACF field key for the video file field.
- Make Public Field Key: ACF True/False field key for the public toggle.

Additional Options:
- reCAPTCHA: Enable v3 (Invisible) with Site Key and Secret Key (recommended). Obtain keys at https://www.google.com/recaptcha/admin.
- Form Access: Restricted to logged-in PMPro members.
- Default Status: Draft (recommended for moderation) or Publish.

Field Setup in ACF Pro:
Create a Group assigned to your CPT. Include:
- Gallery field (for images)
- File field (for video)
- True/False field ("Make Public")

PMPro Integration:
The plugin automatically adds a "My PE Tracker" section to the membership account page. Ensure your PMPro levels have associated tier limits defined in plugin settings or code.

Using the Shortcode:
- Create or edit a page (e.g., "My Pet Tracker") and insert [pe_tracker_uploader].
- Link this page in your membership navigation.
- Members can upload/introduce their pet via video, add images, and toggle public sharing.

Public Visibility:
- Owners always see their entry (even drafts).
- Public users see only published entries where "Make Public" is enabled.
- Clean permalink support for sharing.

Managing Submissions:
Go to your CPT (e.g., Pet Trackers > All Entries) in the admin.
- Moderate drafts.
- View/edit member trackers.
- Published + public entries appear on frontend where appropriate.

Upload Restrictions & Tier Limits:
- Limits are dynamic per PMPro membership level (configured in plugin/code).
- Video size limits enforced client- and server-side.
- Images: Gallery-based (tier-dependent count).
- Warning messages displayed on the form.

Troubleshooting
Form Not Displaying: Ensure ACF Pro is active, user is logged in with a valid PMPro membership, and the CPT + fields exist.
Upload Fails: Check php.ini (upload_max_filesize, post_max_size). Verify ACF field keys in settings.
Tier Limits Not Applying: Confirm PMPro integration and membership level mapping.
reCAPTCHA Issues: Validate keys and domain at Google reCAPTCHA admin.
Sharing/Permalinks: Flush permalinks after changes (Settings > Permalinks).
Debugging: Enable WP_DEBUG and check /wp-content/debug.log.
